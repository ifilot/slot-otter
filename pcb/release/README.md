# Slot-otter historical discrete-logic release

This directory preserves the earlier discrete-logic release hardware. The current design
and OSHWA certification preparation target is [CPLD revision 1.0](../cpld/README.md).
These historical sources are retained for existing cards and are not the
revision 1.0 fabrication package. Use the matching source revision when
repairing or reproducing an older card.

Project-authored hardware remains available under CERN-OHL-S-2.0 and this
documentation under CC-BY-SA-4.0; see [licensing scope](../../LICENSE.md).
