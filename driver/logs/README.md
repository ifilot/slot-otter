# Physical card logs

Keep each NEW run in a separate folder, for example SanDisk-2026-10-07 or
Intenso-2026-10-07. Include the manual's logs plus card/model/CID, DOS/CPU/RAM
and executable hashes. Logs are evidence, not build inputs.
Original read-only, raw-write and resident-writer hardware logs are kept in
`historical/`. They are evidence for those earlier binaries; do not relabel
them as runs of the current executable. Generated release archives, disk
images and build outputs are not stored here.
