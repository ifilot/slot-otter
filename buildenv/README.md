# Build Environment

This folder contains the binaries of Borland's Turbo Assembler v2.0.1 and
Borland's Turbo C compiler v2.0. The binaries were produced using the install
disks obtained from the following links
* https://winworldpc.com/product/turbo-assembler/20
* https://winworldpc.com/product/borland-turbo-c/2x

The project maintainer has permission to bundle these Borland tools here.
They remain proprietary software; Slot-otter's open-source licenses do not
apply to the tools, supplied libraries, examples or Borland documentation.
Retain the supplied notices and follow the applicable Borland terms when
using or redistributing them.

The driver also accepts a separately installed toolchain through
`TOOLCHAIN_DIR`; see [driver build instructions](../driver/README.md).
